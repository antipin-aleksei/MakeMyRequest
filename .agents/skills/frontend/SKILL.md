# Frontend skill
Use React functional components, strict TypeScript and Mantine primitives. Prefer Mantine Form, Stack, Group, Paper, Stepper, Select, TextInput, Textarea, NumberInput, Checkbox, Alert, Button. Keep layout responsive at 320px and WebView-safe. Validate on client for UX, but never rely on it for correctness. Avoid custom CSS unless Mantine layout props are insufficient. Keep strings accessible; label fields, show failures, disable submit while pending. Do not use mock availability as live appointments. Fetch via typed API module, not inside presentational inputs.
