## Этап 03: анкета и изображения
- [x] Параметры идеи, контактные данные и предпочитаемая дата.
- [x] 1–3 файла, серверное ограничение 5 MB, JWT не используется.
- [x] Одноразовый upload bearer secret в ответе на POST, хранится лишь SHA-256 в DB. В течение 24 часов можно добавить файлы.
- [x] Приватный object store: локальная filesystem реализация / S3-совместимый Cloudflare R2.
- [x] Metadata и лимит количества файлов закреплены в миграции Postgres.
- [ ] Отдельная версионированная JSON-схема анкеты, в первой итерации `form_version=1` и фиксированная форма.
- [ ] Клиентский retry ранее частично провалившихся uploads; пока после отправки показывается предупреждение.

## Этап 05: API и безопасность
- [x] DTO и SQLx migrations, репозиторные функции для создания заявки, server-side validation.
- [x] Нет публичных ссылок на загруженные файлы; image bytes проверяются по magic signature; ограничен размер тела запроса.
- [x] Honeypot, CORS по одному точному origin; логирование без содержимого анкеты.
- [ ] Систематический перенос всех SQL запросов из HTTP handlers в repository слой.
- [ ] Полноценный rate limiting/WAF, вирусная проверка изображений и удаление по retention.
- [ ] Privacy policy и security review перед продакшеном.
