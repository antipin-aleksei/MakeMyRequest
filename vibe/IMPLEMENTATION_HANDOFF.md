# Handoff — MVP 02–07

Дата: 2026-11-17. Ветка `feat/mvp-02-07-implementation` (draft PR #8, зависит от PR #1).

## Сделано в коде
- **02:** публичный профиль конкретного мастера из API, два понятных варианта обращения и мобильная форма.
- **03:** фиксированная анкета v1 с описанием, стилем, зоной, размером, бюджетом, контактом, желаемой датой и 1–3 фото. Приватный storage: local / Cloudflare R2; metadata в PostgreSQL.
- **04:** кабинет одного мастера по секретному ключу, список/детали/фильтрация/изменение статусов, авторизованное чтение изображений.
- **05:** Axum API, SQLx миграции, проверка данных, SQL вынесен в repository-функции; ограничение вложений и размера, upload bearer token со сроком 24 часа; CORS и honeypot.
- **06:** Dockerfile/Render Blueprint, инструкция Cloudflare Pages + Neon + R2, staging env и обязательный remote storage.
- **07:** Rust unit-тесты и PostgreSQL-backed HTTP smoke в GitHub Actions, приемочный checklist.
